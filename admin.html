How do I get a token? (2 minutes, do this once)
  1. On your phone, open github.com/settings/personal-access-tokens/new in your browser (or GitHub app → your profile photo → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token).
  2. Give it a name like Vivy Admin.
  3. Under Repository access, choose Only select repositories and pick your Vivy store repository. Do not grant access to any other repository.
  4. Under Permissions → Repository permissions, find Contents and set it to Read and write. Leave everything else as No access.
  5. Set an expiration (e.g. 90 days) — you'll just repeat this in a few months.
  6. Tap Generate token, then copy it and paste it above. GitHub only shows it once.

You can revoke this token at any time from the same GitHub settings page — that instantly blocks any further use of it, including on this page.
